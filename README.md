# rephraser-mk — академический редактор без ИИ

Редактор правит **ваш собственный** научный текст по правилам, словарям и корпусной статистике.
Никаких языковых моделей и сетевых запросов: текст не покидает ваш компьютер.

## Что умеет

- **Автоматические исправления** (зависят от степени вмешательства): типографика, орфография,
  кальки, слова-паразиты, разговорные обороты; русский, украинский, английский.
- **Предложения на выбор**: возможные опечатки, повторы слов, слишком длинные предложения,
  лексическая несочетаемость, «я считаю» в научном тексте.
- **Синонимы** (украинский): по клику на слово, предложением по всему тексту или автозаменой.
  Подбор учитывает соседние слова — по статистике сочетаемости из корпуса. Любую замену можно
  сменить на другой вариант или вернуть.
- **Развёрнутые обороты** («щоб» → «для того щоб»): по желанию, текст становится чуть длиннее.
- **Защита**: ссылки `[3, с. 45]`, `(Іванов, 2019)`, URL, DOI и цитаты в кавычках не меняются;
  после правки числа и ссылки сверяются с оригиналом.
- **Отчёт**: что изменено, список замен и доля изменённых слов.

## Запуск

```bash
pip install -r requirements.txt
python app.py
```

Откройте http://localhost:8765.

## Данные

- `data/th_uk_UA.dat` — украинский тезаурус LibreOffice (А. Рысин, на основе словарей
  П. Деркача и С. Караванського; лицензии GPL/LGPL/MPL), см. `data/README_th_uk_UA.txt`.
- `data/cooc_uk.sqlite` — таблица сочетаемости слов, построенная скриптом `build_stats.py` по
  корпусам [Leipzig Corpora Collection](https://wortschatz.uni-leipzig.de/) (Universität Leipzig,
  CC BY): `ukr_wikipedia_2021_1M` и `ukr_news_2020_1M`.

Пересборка таблицы (например, с другим корпусом): положите архивы `*.tar.gz` в `data/corpus/`
и запустите `python build_stats.py` (несколько минут). Без таблицы автозамена синонимами
работает осторожнее и берёт только однозначные варианты.

## Ограничения

- Редактор **не перестраивает предложения**: длинные и неуклюжие фразы он только помечает.
- Синонимы подбираются по словарю и статистике, а не по смыслу: **результат автозамены нужно
  просматривать целиком**, устойчивые термины могут быть изменены.
- Словарь синонимов есть только для украинского; для русского и английского работают правила.
- Это не средство обхода детекторов ИИ и не гарантирует какой-либо процент «авторства».
  Правила использования автоматических редакторов в вашем вузе уточняйте сами.

## GitHub Pages

Pages раздаёт только статические файлы и не запускает Python-сервер, поэтому в нынешнем виде
(`app.py`) редактор там не заработает: страница откроется, но запросы к `/api/*` будут падать.
Для Pages движок нужно запускать прямо в браузере (например, через Pyodide) — это отдельная работа.
